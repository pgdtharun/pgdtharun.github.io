Projects

CipherSentry

A static analysis tool, written in Python, that scans source code for common cryptographic mistakes: hardcoded secrets, ECB mode, weak hashes (MD5/SHA-1), insecure randomness, deprecated ciphers and undersized RSA keys. It parses code into a syntax tree with Python's ast module and walks it looking for risky patterns, rather than matching raw text. Six detection rules (CM001 to CM006), tested against both vulnerable and safe samples.
